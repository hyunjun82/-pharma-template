# 유튜브 시니어 채널 대본 생성기

김은숙 작가 스타일의 감동적인 스토리텔링으로 1시간 20분~2시간 분량의 시니어 채널용 대본을 자동 생성하는 도구입니다.

## 특징

- **김은숙 작가 스타일**: 감동적이고 극적인 전개, 인간미 넘치는 스토리텔링
- **기승전결 구조**: 체계적인 4막 구성으로 완성도 높은 대본 생성
- **다양한 주제**: 8개 카테고리, 30+ 개의 시니어 공감 주제
- **유연한 길이**: 80분~180분까지 자유롭게 설정 가능
- **다양한 출력 형식**: TXT, JSON, Markdown 지원

## 주요 주제 카테고리

1. **인생역전** - 평범한 삶에서 찾아온 놀라운 변화
2. **가족애** - 가족 간의 사랑과 화해, 재회
3. **우정** - 오랜 우정과 새로운 인연
4. **도전과성취** - 늦은 나이의 도전과 성공
5. **사랑** - 운명적 만남과 황혼의 로맨스
6. **지혜와교훈** - 인생에서 배운 귀중한 가르침
7. **역사와추억** - 격동의 시대를 살아온 이야기
8. **극복과회복** - 시련을 이겨낸 감동 스토리

## 사용 방법

### 1. 프로그램을 통한 사용

```python
from senior_youtube_script_generator import SeniorScriptGenerator

# 생성기 초기화
generator = SeniorScriptGenerator()

# 랜덤 주제로 대본 생성 (100분 분량)
script = generator.generate_script(duration_minutes=100)

# 특정 주제로 대본 생성
script = generator.generate_script(
    theme="인생역전",
    topic="60대에 시작한 작은 가게가 대성공한 이야기",
    duration_minutes=120  # 2시간
)

# 파일로 저장
generator.export_script(script, "output/my_script.txt", format='txt')
generator.export_script(script, "output/my_script.md", format='md')
generator.export_script(script, "output/my_script.json", format='json')
```

### 2. 대화형 모드

```bash
cd examples
python generate_sample_scripts.py
# 1번 선택 → 대화형 모드
```

대화형 모드에서는:
- 주제 카테고리 선택
- 구체적인 주제 선택
- 대본 길이 설정
- 자동으로 여러 형식으로 저장

### 3. 커맨드라인에서 직접 실행

```bash
# 기본 실행 (랜덤 주제, 100분)
python src/senior_youtube_script_generator.py

# 결과는 output/ 디렉토리에 저장됩니다
```

## 대본 구조

생성되는 대본은 다음과 같은 구조로 이루어집니다:

### 1. 오프닝 (5%)
- 청중에게 인사
- 오늘의 주제 소개
- 시청자의 관심 유도

### 2. 제1막: 기(起) (25%)
- 주인공과 배경 소개
- 일상적인 상황 묘사
- 변화의 조짐

### 3. 제2막: 승(承) (28%)
- 전개와 발전
- 작은 변화의 시작
- 희망이 보이기 시작

### 4. 제3막: 전(轉) (22%)
- 갈등과 위기
- 최대의 시련
- 절망의 순간

### 5. 제4막: 결(結) (15%)
- 문제 해결
- 깨달음
- 감동적인 결말

### 6. 클로징 (5%)
- 이야기 마무리
- 교훈과 메시지
- 시청자에게 작별 인사

## 출력 형식

### TXT 형식
```
================================================================================
  60대에 시작한 작은 가게가 대성공한 이야기
================================================================================

주제: 인생역전
예상 길이: 100분
생성일시: 2025-11-10T...
================================================================================

안녕하세요, 여러분...
[대본 내용]
...
================================================================================
끝
================================================================================
```

### JSON 형식
```json
{
  "metadata": {
    "theme": "인생역전",
    "topic": "60대에 시작한 작은 가게가 대성공한 이야기",
    "duration_minutes": 100,
    "style": "김은숙작가",
    "generated_at": "2025-11-10T...",
    "word_count_estimate": 15000
  },
  "opening": "...",
  "act1_ki": "...",
  "act2_seung": "...",
  "act3_jeon": "...",
  "act4_gyeol": "...",
  "closing": "..."
}
```

### Markdown 형식
```markdown
# 60대에 시작한 작은 가게가 대성공한 이야기

**주제**: 인생역전
**예상 길이**: 100분
**생성일시**: 2025-11-10T...

---

[대본 내용]
```

## 주요 기능

### 1. 다양한 스토리 템플릿

각 주제별로 고유한 기승전결 템플릿이 준비되어 있어 일관성 있는 스토리 전개가 가능합니다.

### 2. 풍부한 주제 데이터베이스

30개 이상의 시니어가 공감할 수 있는 주제들:
- 인생역전: 말년의 성공, 재기 스토리
- 가족애: 재회, 화해, 세대 간 이해
- 우정: 오랜 우정, 새로운 만남
- 도전과성취: 늦은 나이의 도전
- 사랑: 황혼의 로맨스, 재회
- 지혜와교훈: 인생의 가르침
- 역사와추억: 시대를 살아온 이야기
- 극복과회복: 시련 극복 스토리

### 3. 길이 자동 조절

설정한 시간에 맞춰 자동으로 내용의 양을 조절합니다:
- 80분 (1시간 20분): 약 12,000자
- 100분 (1시간 40분): 약 15,000자
- 120분 (2시간): 약 18,000자

### 4. 감동적인 스토리텔링 요소

- 생생한 배경 묘사
- 입체적인 인물 묘사
- 극적인 복선과 반전
- 진심 어린 교훈과 메시지
- 감동적인 결말

## 활용 예시

### 유튜브 시니어 채널용

```python
generator = SeniorScriptGenerator()

# 일주일치 콘텐츠 생성
themes = ["인생역전", "가족애", "우정", "사랑", "지혜와교훈"]

for i, theme in enumerate(themes, 1):
    script = generator.generate_script(
        theme=theme,
        duration_minutes=100
    )
    generator.export_script(script, f"output/week1_day{i}.txt", 'txt')
    generator.export_script(script, f"output/week1_day{i}.md", 'md')
```

### 팟캐스트용 대본

```python
# 긴 분량의 대본 생성 (2시간)
script = generator.generate_script(
    theme="역사와추억",
    topic="1960년대 서울의 변화를 목격한 택시기사 이야기",
    duration_minutes=120
)

generator.export_script(script, "output/podcast_ep1.txt", 'txt')
```

### 오디오북용 스크립트

```python
# 짧은 분량의 감동 스토리 (1시간 20분)
script = generator.generate_script(
    theme="극복과회복",
    topic="불치병을 이겨낸 할아버지의 긍정 에너지",
    duration_minutes=80
)

generator.export_script(script, "output/audiobook_chapter1.txt", 'txt')
```

```python

    "category": "새로운카테고리",
    "topics": [
        "새로운 주제 1",
        "새로운 주제 2",
        "새로운 주제 3"
    ]
}
```

## 팁과 권장사항

### 1. 최적의 길이
- **1시간 20분 (80분)**: 간결하고 임팩트 있는 스토리
- **1시간 40분 (100분)**: 균형잡힌 스토리텔링 (추천)
- **2시간 (120분)**: 깊이 있는 감동 스토리

### 2. 주제 선택
- 시니어 청중의 경험과 공감대를 고려
- 긍정적이고 희망적인 메시지 포함
- 실제 있을 법한 현실적인 이야기 선호

### 3. 활용 방법
- 생성된 대본을 기본 틀로 활용
- 실제 사연이나 인터뷰를 추가하여 풍부하게 구성
- 청중 반응을 보고 길이와 주제 조정

### 4. 편집 권장
- 생성된 대본을 그대로 사용하기보다는
- 채널의 특성과 스타일에 맞게 편집
- 실제 사례와 통계 추가로 신뢰도 향상
