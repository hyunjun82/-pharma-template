# 이미지 애니메이션 비디오 생성기

이미지 10장을 생동감 있게 움직이는 40초 동영상으로 자동 변환해주는 도구입니다.

## 특징

- 🎬 **생동감 있는 애니메이션**: Ken Burns 효과 (줌인/아웃, 팬 이동, 회전)
- 🖱️ **간편한 사용**: 드래그앤드롭으로 이미지 업로드
- 📦 **설치 불필요**: HTML 파일만 열면 바로 사용 가능
- 🎨 **원본 화질 유지**: 이미지 왜곡 없이 자연스러운 전환
- 💰 **완전 무료**: 인터넷 연결 없이 로컬에서 작동

## 사용 방법

1. `image-animator.html` 파일을 더블클릭하여 브라우저로 열기
2. 화면에 이미지 10장을 드래그앤드롭
3. "영상 만들기" 버튼 클릭
4. 자동으로 생성된 `animated-video.mp4` 다운로드

## 시스템 요구사항

- 최신 버전의 크롬(Chrome) 또는 엣지(Edge) 브라우저
- 최소 4GB RAM 권장

## 주의사항

- 이미지 해상도가 높을수록 처리 시간이 길어집니다
- 처리 중에는 브라우저 탭을 닫지 마세요
